# Referências

Os PDFs desta pasta ficam fora do repositório (ver `.gitignore`): são textos de
terceiros e pesam. Ficam aqui só para leitura local.

- Jordan Taylor, *Graphical tensor notation for interpretability*.
  LessWrong, 4 out. 2023 · [arXiv:2402.01790](https://arxiv.org/abs/2402.01790) ·
  [post original](https://www.lesswrong.com/posts/BQKKQiBmc63fwjDrj/graphical-tensor-notation-for-interpretability)

  A origem da ideia do MOIRA. A primeira metade é um tutorial de notação de
  Penrose — pernas, contração, deltas, isometrias, SVD, MPS, gauge — e fixa as
  convenções que o MOIRA adota. A segunda metade aplica a notação a circuitos de
  transformer, com "bolhas" para não-linearidades: isso é não-objetivo explícito
  do MOIRA (ver `docs/moira-spec.md`, §2).
